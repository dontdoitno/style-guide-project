# Глоссарий

Расшифровки сокращений и терминов, которые встречаются в документах SONDER. Правило расшифровки при первом употреблении – в разделе [«Орфография, числа и даты»](spelling.md). Термины продукта – в разделе [«Терминология и ограничения»](terminology.md).

## Как пользоваться

В тексте для команды достаточно аббревиатуры, если она есть в этом списке. В тексте для клиники или пациента расшифровывайте при первом употреблении или заменяйте обычным словом.

> **Пример.**
> Для команды: «Согласие подтверждается ПЭП».
> Для клиники: «Согласие подтверждается простой электронной подписью – кодом из СМС».
> Для пациента: «Подтвердите согласие кодом из СМС».

## Русскоязычные сокращения

| Сокращение | Расшифровка | Как использовать |
| --- | --- | --- |
| 152-ФЗ | Федеральный закон «О персональных данных» | «Обработка данных регулируется 152-ФЗ.» Для клиники – с расшифровкой. |
| КП | Неоднозначно: коммерческое предложение или контент-план | Не сокращайте. Пишите «коммерческое предложение» или «контент-план». |
| МИС | Медицинская информационная система | «Интеграция с МИС планируется.» |
| ПДн | Персональные данные | В документах для команды. В тексте для пациента – «ваши данные». |
| ПЭП | Простая электронная подпись | «Согласие подтверждается ПЭП – кодом из СМС.» |
| РКН | Роскомнадзор | Для команды. Для читателя вне команды – полностью. |
| УЗ | Уровень защищённости персональных данных | Только в технических документах. |
| ФСИ | Фонд содействия инновациям | «Заявка в ФСИ.» Расшифруйте при первом упоминании. |
| ЕСИА | Единая система идентификации и аутентификации | В документах об архитектуре. |

## Английские сокращения

| Сокращение | Расшифровка | Как использовать |
| --- | --- | --- |
| API | Интерфейс, через который программы обмениваются данными | Только в технических документах; клиникам – «подключение». |
| ARPA | Средняя выручка с одной клиники за период | «ARPA – X ₽/мес. (версия от ДД.ММ.ГГГГ).» |
| ARR | Годовая повторяющаяся выручка | Указывайте дату расчёта. |
| B2B | Продажи бизнесу (клиникам) | «B2B-продажи клиникам.» |
| B2C | Продажи частным лицам (пациентам) | Не пишите в текстах для пациентов. |
| CAC | Стоимость привлечения одной клиники | Указывайте способ расчёта. |
| ICP | Идеальный профиль клиента | Для команды. |
| LTV | Выручка с одной клиники за всё время сотрудничества | Указывайте допущение об оттоке. |
| MVP | Минимально жизнеспособный продукт | «Стадия Pre-MVP» – до выпуска минимальной версии. |
| SaaS | Программа, которая работает по подписке в интернете | В текстах для клиник: «сервис по подписке». |
| SAM, SOM, TAM | Ёмкость рынка: доступная, достижимая, общая | Указывайте версию расчёта. |

## Как писать сокращения

- Пишите заглавными буквами, без точек: «МИС», «ПЭП».
- В единственном и множественном числе сокращение не меняется: «две МИС».
- Падежные окончания не добавляйте через дефис: «в МИС клиники», а не «в МИС-е».

| Плохо | Хорошо |
| --- | --- |
| Интегрируемся с мис-ами. | Интегрируемся с МИС клиник. |
| Нужно ПЭП-ом подтвердить. | Нужно подтвердить согласие с помощью ПЭП. |

## Как добавить термин

Добавляйте термин в глоссарий, если он встречается в двух и более документах и его может не знать новый читатель. В записи укажите расшифровку и пример употребления. Затем внесите запись в [историю изменений](changelog.md).
