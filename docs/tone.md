# Тон и стиль

Тон зависит от того, кто читает и где текст появится. Точность одинаково обязательна везде.

## Два регистра

| | Документы для команды | Маркетинговые материалы |
| --- | --- | --- |
| Тон | Прямой, конкретный, деловой | Живой, тёплый, допустимы эмоции |
| Цель | Чтобы коллега быстро понял и сделал | Чтобы читатель заинтересовался и понял пользу |
| Обращение | Безлично или «мы» | «Вы» с маленькой буквы |
| Ограничение | Не прячьте вывод в конец | Не жертвуйте точностью ради эмоции |

> **Пример для команды.**
> «Анкета содержит 24 вопроса в 5 разделах. Ветвление включено для вопросов об аллергии. Срок реализации – до 15.11.2026».
>
> **Пример для маркетинга.**
> «Пациент отвечает на вопросы дома, без спешки в коридоре клиники. Врач открывает ответы до приёма и сразу видит, что обсудить».

Числа в примерах иллюстративные.

## Пишите конкретно

Заменяйте неопределённые слова фактами, а абсолютные слова – проверяемыми утверждениями.

| Плохо | Хорошо |
| --- | --- |
| Идеальное решение для любой клиники | Решение для клиник, где врач собирает анамнез до визита |
| Полностью безопасный сервис | Данные хранятся на серверах в России, доступ ограничен по ролям |
| Всё в одном месте | Анкеты и согласия пациента в одном месте |
| Быстро заполняется | Анкета заполняется за 5–7 минут (замер на бета-группе, 20.11.2026) |
| Лучшее на рынке | Собирает анкету и согласие пациента по одной ссылке |

Замер в предпоследнем примере иллюстративный: подставляйте только подтверждённые данные.

## Одна основная мысль в предложении

Если в предложении две мысли, разделите их. Если предложение длиннее 25 слов, разбейте его (см. [«Доступность»](accessibility.md)).

| Плохо | Хорошо |
| --- | --- |
| Пациент получает ссылку по СМС, заполняет анкету, подтверждает согласие кодом, после чего врач видит ответы в карточке, а клиника хранит документы в одном месте. | Пациент получает ссылку по СМС и заполняет анкету. Согласие он подтверждает кодом из СМС. Врач видит ответы в карточке, а клиника хранит документы в одном месте. |

## Активный залог и глаголы

Называйте действующего: кто что делает. Заменяйте отглагольные существительные глаголами.

| Плохо | Хорошо |
| --- | --- |
| Осуществляется отправка анкеты пациенту. | Система отправляет анкету пациенту. |
| Производится проверка заполненности. | Система проверяет, что пациент ответил на все обязательные вопросы. |
| Имеет место быть задержка. | Отправка задерживается. |

## Канцелярит и штампы

Не используйте слова, которые добавляют длину, но не смысл.

| Плохо | Хорошо |
| --- | --- |
| В рамках реализации функционала | Для этой функции |
| Является важным элементом | Нужна для |
| Данный продукт | Продукт или SONDER |
| На сегодняшний день в настоящее время | Сейчас |
| Инновационное передовое решение | Не пишем: слова пустые, назовите конкретное свойство |

## Адресат указан явно

При описании ценности называйте, кому адресовано сообщение: косметологу, управляющему клиники или пациенту. Сообщение для всех сразу не работает ни для кого. Подробно – в разделе [«Аудитории и формулировки»](audiences.md).

| Плохо | Хорошо |
| --- | --- |
| Удобно для всех участников процесса. | Косметолог видит ответы пациента до приёма. Управляющий видит, у каких пациентов анкета не заполнена. |

## Эмоции, восклицания, эмодзи

- В документах для команды обходитесь без восклицательных знаков и эмодзи.
- В постах допустим один восклицательный знак на текст и один-два эмодзи, если они не заменяют слова. Пример: «Заполните анкету до визита – и врач заранее увидит ваши ответы».
- Не используйте капслок для выделения. Выделяйте ключевое слово жирным.
- Не пугайте читателя. Не пишите «осложнения» и «риски» в рекламных заголовках; говорите о подготовке к разговору с врачом.

| Плохо | Хорошо |
| --- | --- |
| ВНИМАНИЕ!!! Без анкеты опасно идти на процедуру!!! | Анкета помогает врачу заранее узнать о вашем самочувствии и аллергиях. |

## Обращение

- Пациенту и клиенту пишите на «вы» с маленькой буквы: «Заполните анкету».
- Коллегам в документах допустимо «мы»: «Мы выбрали ветвление анкеты».
- Не обращайтесь к читателю на «ты» в материалах для клиник и пациентов.

## Сокращения и жаргон

Профессиональный жаргон допустим, если его знает читатель.

| Читатель | Можно | Нужно пояснять |
| --- | --- | --- |
| Команда | MVP, CAC, ICP | Внутренние сокращения новых коллег |
| Косметолог | анамнез, процедура, показания | MVP, SaaS, API |
| Пациент | анкета, согласие | анамнез (лучше «информация о вашем здоровье»), любые аббревиатуры |

Расшифровки сокращений – в [глоссарии](glossary.md).
