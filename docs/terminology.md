# Терминология и ограничения

Название проекта пишется SONDER – заглавными латинскими буквами. Для подготовки любых маркетинговых текстов необходимо обращаться к документу «Словарь формулировок», обозначенному в стратегии как обязательный.

## Как называть продукт

Опорная формулировка: **платформа предварительного сбора, структурирования и хранения анамнестических анкет и согласий пациента**.

Она допускает сокращения, если смысл не меняется.

| Где | Формулировка |
| --- | --- |
| Полное описание | SONDER – платформа предварительного сбора, структурирования и хранения анамнестических анкет и согласий пациента. |
| Короткое описание | SONDER – сервис предварительных анкет для косметологов. |
| Одна фраза для поста | SONDER собирает анамнез пациента до визита и хранит ответы в одном месте. |
| Не пишем | SONDER – умная система оценки рисков перед процедурой. |

SONDER не является медицинским изделием. Система собирает, группирует, показывает и хранит ответы. Она не интерпретирует медицинские данные и не принимает клинических решений.

## Предпочтительные и нежелательные формулировки

| Предпочтительно / допустимо | Избегать без отдельного подтверждения | Причина |
| --- | --- | --- |
| «сбор анамнеза», «предварительная анкета», «структурирование ответов пациента» | «преддиагностика», «выявляет противопоказания», «оценивает риски», «поддержка принятия решений», «AI/ИИ» как описание функции | В маркетинговой стратегии эти формулировки обозначены как потенциально влияющие на трактовку назначения продукта. |
| «Система показывает ответы пациента» | «Система оценивает состояние пациента» | В документации указано, что система не интерпретирует медицинские данные и не принимает клинические решения. |
| «планируется», «цель», «гипотеза», «на этапе разработки» | Описание планируемой функции как уже работающей | Проект находится на стадии Pre-MVP. |
| «может помочь организовать сбор информации» — если это соответствует текущей концепции | «гарантирует безопасность», «исключает осложнения», «защищает от любых претензий» | Не следует обещать медицинский или юридический результат без подтверждения. |

## Красный список

Эти слова и обороты не используются в материалах о SONDER: на сайте, в презентациях, коммерческих предложениях, документах, интерфейсе. Причина общая: по ним можно решить, что продукт интерпретирует медицинские данные. Цель – сохранить точное описание продукта.

| Не пишем | Пишем вместо этого | Пример замены |
| --- | --- | --- |
| преддиагностика | предварительный сбор анамнеза | «Преддиагностика до приёма» → «Сбор анамнеза до приёма» |
| помощь в диагностике | подготовка врача к приёму | «Помогает в диагностике» → «Врач заранее видит ответы пациента» |
| выявляет противопоказания | показывает ответы пациента | «Выявляет противопоказания» → «Показывает ответы об аллергиях и принимаемых препаратах» |
| оценка риска, уровни риска | группировка ответов по разделам | «Оценка риска по анкете» → «Ответы сгруппированы по разделам анкеты» |
| красные флаги | отмеченные пациентом ответы | «Красные флаги в анкете» → «Ответы, на которые стоит обратить внимание, отмечает врач» |
| поддержка принятия решений | структурирование ответов для врача | «Система поддерживает решения врача» → «Ответы структурированы в карточке пациента» |
| движок правил, база правил | ветвление анкеты, контроль полноты формы | «Движок правил выбирает вопросы» → «Анкета показывает следующие вопросы в зависимости от ответов» |
| ИИ, AI, искусственный интеллект, нейросеть, машинное обучение | описание действия без слов о технологии | «ИИ анализирует анкету» → «Система группирует ответы по разделам» |
| гарантирует безопасность, исключает осложнения | помогает организовать сбор и хранение информации | «Исключает осложнения» → «Помогает врачу заранее узнать о состоянии здоровья пациента» |
| защищает от любых претензий, юридическая защита | хранит согласия и ответы пациента | «Защитит от претензий» → «Хранит подписанные согласия вместе с анкетой» |

Продукт не использует ИИ. Не называйте так ни одну функцию, даже если так делают конкуренты или так написано в старых материалах.

## Разрешённые действия системы

Описывайте работу системы этими глаголами. Они отражают то, что продукт делает на самом деле.

| Действие | Что означает | Пример |
| --- | --- | --- |
| Собирает | Получает ответы пациента | Система собирает ответы пациента до визита. |
| Структурирует | Раскладывает по разделам и полям | Система структурирует ответы по разделам анкеты. |
| Группирует | Объединяет ответы по теме | Ответы об аллергиях сгруппированы в одном разделе. |
| Показывает, отображает | Выводит врачу без оценки | Врач видит ответы пациента в карточке. |
| Хранит | Сохраняет анкеты и согласия | Система хранит подписанные согласия вместе с анкетой. |
| Ветвит анкету | Показывает вопросы в зависимости от ответа | Если пациент отвечает «Да», появляется уточняющий вопрос. |
| Считает по формуле | Вычисляет значение по заданной формуле, без оценки | Система считает возраст пациента по дате рождения. |
| Сравнивает заполнения | Показывает различия между анкетами без вывода | Система показывает, какие ответы изменились с прошлого визита. |
| Контролирует полноту | Проверяет, что обязательные поля заполнены | Система не отправляет анкету, пока не заполнены обязательные вопросы. |

Нельзя: «оценивает», «определяет», «диагностирует», «предупреждает о риске», «рекомендует», «анализирует состояние».

## Что система делает и чего не делает

Если пишете о границах продукта, используйте пары утверждений.

| Система делает | Система не делает |
| --- | --- |
| Собирает и хранит ответы пациента | Не интерпретирует ответы |
| Показывает ответы врачу в удобном виде | Не рекомендует процедуры или препараты |
| Сохраняет подтверждённое согласие | Не заменяет консультацию врача |
| Помогает врачу подготовиться к разговору | Не принимает клинических решений |

> **Пример в тексте.**
> «Система показывает врачу ответы пациента. Решение о процедуре принимает врач на приёме».

## Если сомневаетесь в слове

Задайте три вопроса:

1. Описывает ли слово действие системы: собрать, показать, сохранить?
2. Можно ли из слова понять, что система оценила состояние пациента?
3. Есть ли это слово в красном списке или рядом с ним по смыслу?

Если на второй или третий вопрос ответ «да», замените слово. Если замены нет, спросите у команды до публикации.

> **Пример.**
> Слово: «подсказывает врачу противопоказания».
> Вопрос 2: да, из слова следует, что система оценила данные. Замена: «показывает врачу ответы об аллергиях и принимаемых препаратах».
