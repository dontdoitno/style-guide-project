## Структура документа

- Начинайте документ с содержательного заголовка, при необходимости добавляйте краткое описание и теги.
- Используйте иерархию Markdown: # – название документа; ## – раздел; ### – подраздел.
- Соблюдайте одну основную тему на раздел.
- Для сопоставления однотипных данных используйте таблицы; для перечислений – маркированные списки; для последовательности действий – нумерованные.
- В конце документа при необходимости размещайте раздел «Связанные заметки» с полезными внутренними ссылками.
