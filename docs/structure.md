# Структура документа

Документ должен читаться сверху вниз и позволять найти нужное по заголовкам. Читатель решает, нужен ли ему документ, по названию и первому абзацу.

## Начало документа

Начинайте документ с содержательного заголовка, при необходимости добавляйте краткое описание и теги.

| Плохо | Хорошо |
| --- | --- |
| Заметка 3 | Правила заполнения анкеты пациентом |
| Разное | Ограничения первой версии анкеты |
| Черновик | Описание тарифов SONDER (редакция от 20.10.2026) |

Пример начала документа:

```markdown
---
tags: [анкета, продукт]
---

# Правила заполнения анкеты пациентом

Документ описывает, как пациент получает ссылку на анкету, заполняет её и подтверждает согласие. Статус: действует с 01.11.2026.
```

## Иерархия заголовков

Используйте иерархию Markdown: `#` – название документа; `##` – раздел; `###` – подраздел.

- Один заголовок `#` на документ.
- Не пропускайте уровни: после `##` идёт `###`, а не `####`.
- Не используйте жирный шрифт вместо заголовка.
- Заголовок раздела отвечает на вопрос «о чём этот раздел»: существительное или короткая фраза.

| Плохо | Хорошо |
| --- | --- |
| `#` Анкета<br>`###` Вопросы<br>`##` Ограничения | `#` Анкета пациента<br>`##` Вопросы<br>`##` Ограничения |

## Одна тема на раздел

Соблюдайте одну основную тему на раздел. Если в разделе появляется «а ещё», вынесите новую тему в отдельный раздел.

| Плохо | Хорошо |
| --- | --- |
| Раздел «Анкета и тарифы» с описанием вопросов и цен | Раздел «Анкета» и раздел «Тарифы» |
| Раздел «Прочее» со всем, что не поместилось | Каждый материал в своём разделе |

## Абзацы

- Один абзац – одна мысль. Обычно два–пять предложений.
- Главную мысль абзаца ставьте в первое предложение.
- Если абзац длиннее восьми строк, разбейте его или превратите в список.

Пример:

> **Плохо.** Анкета нужна для разных целей, и её заполняют перед процедурой, при этом врач может посмотреть ответы заранее, а клиника хранит согласия и анкеты вместе, поэтому удобно, что всё в одном месте, хотя бумажный вариант тоже можно оставить.
>
> **Хорошо.** Пациент заполняет анкету до процедуры. Врач видит ответы заранее. Клиника хранит анкеты и согласия вместе. Бумажный вариант можно оставить для пациентов, которые не могут заполнить анкету онлайн.

## Что выбрать: таблицу, маркированный или нумерованный список

| Для чего | Что использовать | Пример |
| --- | --- | --- |
| Сравнить однотипные данные по нескольким признакам | Таблица | Тарифы по параметрам, формулировки «плохо – хорошо» |
| Перечислить равноправные элементы | Маркированный список | Разделы анкеты |
| Описать последовательность действий | Нумерованный список | Шаги заполнения анкеты |
| Объяснить, обосновать, рассказать | Абзац | Описание причин решения |

Пример нумерованного списка:

1. Клиника отправляет пациенту ссылку на анкету.
2. Пациент заполняет анкету.
3. Пациент подтверждает согласие кодом из СМС.
4. Врач открывает ответы в карточке пациента.

Пример маркированного списка:

- Общие сведения о пациенте.
- Аллергии.
- Принимаемые препараты.
- Хронические заболевания.
- Предыдущие процедуры.

Не используйте нумерацию, если порядок неважен, и маркеры, если порядок важен.

## Таблицы

- Первая строка – заголовки столбцов.
- В столбце – данные одного типа.
- Не больше 5–6 столбцов: широкая таблица плохо читается на телефоне.
- Если таблица занимает больше одного экрана, разделите её.

Пример хорошей таблицы:

| Раздел анкеты | Количество вопросов | Обязательный |
| --- | --- | --- |
| Общие сведения | 6 | Да |
| Аллергии | 5 | Да |
| Принимаемые препараты | 4 | Нет |

Данные в примере иллюстративные.

## Связанные заметки

В конце документа при необходимости размещайте раздел «Связанные заметки» с полезными внутренними ссылками. Добавляйте только материалы, которые помогают понять текущий документ.

```markdown
## Связанные заметки

- [[Анкета пациента]]
- [[Согласие на обработку данных|Текст согласия для пациента]]
- [[Терминология и ограничения]]
```

## Примеры целых структур

### Описание функции

1. Название функции.
2. Для кого и зачем.
3. Как работает (шаги).
4. Ограничения и статус.
5. Связанные заметки.

### Аналитическая записка

1. Вывод в одном абзаце.
2. Данные и источники.
3. Анализ.
4. Допущения и ограничения.
5. Что делаем дальше.
