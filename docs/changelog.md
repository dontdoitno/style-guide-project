# История изменений

Здесь фиксируются изменения руководства. Новые записи добавляйте сверху.

## Как вести историю

Каждая запись содержит дату, раздел и краткое описание. Пишите, что изменилось для читателя, а не какие файлы затронуты.

| Плохо | Хорошо |
| --- | --- |
| Правки в terminology.md | Терминология: добавлены красный список с заменами и таблица основных терминов |
| Обновление | Орфография: уточнён формат процентов и диапазонов |
