## Доступность текста

Документация SONDER должна быть понятной читателям с разным уровнем подготовки. При подготовке материалов необходимо учитывать следующие правила:

- Используйте понятные заголовки, которые отражают содержание раздела.
- Не передавайте смысл только с помощью цвета, например обозначая важную информацию исключительно красным или зелёным цветом.
- Для ссылок используйте информативные подписи, из которых понятно, куда они ведут.
- Не перегружайте текст длинными предложениями, сложными конструкциями и необъяснимыми сокращениями.
- Для таблиц используйте понятные заголовки столбцов и сохраняйте логичную структуру данных.
- Для изображений, содержащих важную информацию, добавляйте текстовое описание. Декоративные изображения не должны заменять текстовые инструкции.
- Предупреждения и ограничения продукта формулируйте однозначно, чтобы читатель мог понять их без дополнительного контекста.

Перед публикацией необходимо проверить, понятны ли заголовки и ссылки, можно ли понять основную информацию без визуальных подсказок и не затрудняют ли оформление и формулировки восприятие текста.
